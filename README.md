# Philip Warkentien II

I'm a Frontend/UI Engineer working with React, TypeScript, and CSS. I build interfaces people can feel: thoughtful motion, expressive details, and complex interactions that make sense.

I enjoy the space where visual ideas meet engineering constraints. That might mean drawing a creature in CSS, exploring what a browser can do without JavaScript, or shaping a design system that stays coherent as a product grows. I care about the architecture behind the interface as much as the way it moves.

## A few things to explore

These experiments span 2019–2024; each explores a different part of interface craft.

- **[Desert Racer](https://000699350.deployed.codepen.website/pages/home/home.html#color-1)** — A CSS-only driving game using scroll-driven animations for swipe input and collision detection. [How it works](https://dev.to/warkentien2/desert-racer-worlds-first-css-only-swipe-aware-game-4j0h).
- **[Curious Geckos](https://codepen.io/warkentien2/pen/jOJJwEp)** — A miniature gecko playground that responds to pointer position using HTML and CSS, without JavaScript. [Build notes](https://dev.to/warkentien2/curious-geckos-the-most-precise-css-only-position-aware-mini-game-16i2).
- **[Gooey React menu](https://github.com/warkentien2/react-gooey-fab)** — A floating action menu experiment combining React, SVG filters, and GSAP to make buttons stretch and separate like liquid.
- **[CSS creatures](https://warkentien2.com/)** — A tarantula and moth drawn in CSS and brought to life with React and GSAP in my original portfolio.

My enterprise work includes frontend architecture and design systems. I also enjoy mentoring and helping teams build a shared understanding of their craft. I'm interested in Staff-level Frontend, UI Engineering, and Design Engineering opportunities.
